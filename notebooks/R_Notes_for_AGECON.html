R Notes for AGECON: Basics and Fundamentals

Walter Ac-Pangan, Ph.D. · August 2024

These notes introduce R for agricultural economics. The examples are intentionally basic and use economics problems throughout. The same topics are covered in the Py, SAS and Stata Notes.

Run the examples in RStudio. Results are not shown on this page: run each example yourself to see them. Most sections create their own practice data, and the examples marked to use your own folder need your own path. The data import example uses the course file demographics.csv: keep it in your working directory.

1 Introduction to R studio

R is a powerful programming language and software environment for statistical computing and graphics. It is widely used among statisticians and data miners for developing statistical software and data analysis. R is an open-source software, which means it is free to use and distribute. R is a command-line driven program, but there are several graphical user interfaces (GUIs) available, such as RStudio, which make it easier to use. RStudio is a powerful and productive user interface for R. It’s free and open-source, and works great on Windows, Mac, and Linux.

R studio is a powerful integrated development environment (IDE) for R. It includes a console, syntax-highlighting editor that supports direct code execution, as well as tools for plotting, history, debugging, and workspace management. RStudio is available in open-source and commercial editions and runs on the desktop (Windows, Mac, and Linux) or in a browser connected to RStudio Server or RStudio Server Pro (Debian/Ubuntu, RedHat/CentOS, and SUSE Linux).

1.1 Installation

To install R and R Studio, go to https://posit.co/download/rstudio-desktop/ and download the appropriate version for your operating system. Follow the instructions to install R and R Studio on your computer.

1.2 RStudio Interface

Let's start by opening RStudio. Then, click File--->New File--->R Script. Once done opening the new R script, you should see four panes.

  1. The Source pane. This is where you write your code. By default, an unnamed R script will be titled Untitled1.
  2. The Console pane. This is where your code from the Source is executed. You can also type and perform short and quick calculations.
  3. The Environment/History pane. This is where you can view what objects are in your working space (environment).
  4. The Files/Plots/Packages/Help pane. This is where you can see file directories, view plots, etc.

You adjust display settings and pane arrangement under Tools--->Global Options....

2 The Basics

2.1 Executing Code & Variable Creation

Below are a few lines of code. You can either type these into your Source pane or copy and paste from this document.

w <-10 # assign the value 10 to the variable "w"
20 -> x # assign the value 20 to the variable "x"
y = 30

To execute line by line, click somewhere within the desired line and then click the Run button in the upper right corner of the Source pane. To execute many lines at once, use your cursor to highlight the selected lines and then click the Run button. Do this for the above lines.

You have just assigned the value 1 to the variable x and the value 2 to the variable y. Notice there are two assignment operators: <- and =. They work identically in this case. However, = is also used inside functions to set parameter values. I suggest using <- as your assignment operator to avoid confusion.

Now run:

x; y # Print "x" and "y".

The values of x and y should print to your Console.

2.2 R is Case Sensitivity

Now run:

x<-5 # Re-assign a new value to variable "x".
a<-10
A<-20
x; a; A # Print "x", "a", and "A".

You have just seen that you can re-assign a new value to a variable. Be mindful of this as your R scripts grow and include many variables.

Also, R is case sensitive. a above equals 10. A equals 20.

Putting # in front of portions of code prevents it from being executed. Commenting out code is useful to provide yourself notes/reminders.

2.3 Missing Values

A missing value in R is defined as NA. Keep in mind that 'NA' is not equal to Zero.

x <- NA
x


Function and math operations will not work with missing values.

x+1
sum(1,x,3)


However, some functions allow you to omit missing values before performing the operation. Setting na.rm equal to TRUE below will omit the missing value before summing across the remaining values.

sum(1,x,3,na.rm=TRUE)

2.4 Calculator and Math Functions

We will pick up the pace now. Comments are provided throughout the document to provide explanation of the functions. Let us set x=3 and y=7.

x<-3 # Re-assign a new value to variable "x".
y<-7
x; y


The lines of code below demonstrate basic mathematical operations in R.

x+y # addition
x-y # subtraction

x*y # multiplication
x/y # division
x*y*1-y
x*y*(1-y) # use parentheses to control order of operations

x^2 # exponent
sqrt(x) # square root

abs(x-y) # absolute value
log(x) # log base e, natural log
log(x,10) # log base 10


Logical operators:

x==y # is "x" equal to "y"?
x!=y # is "x" not equal to "y"?
x<10 # is "x" less than 10?
x<=2 # is "x" less than or equal to 2?
x<20 & y>=50 # is "x" less than 20 AND "y" greater than or equal to 50?

If-else statements...

Two more operators are very useful. Integer division %/% returns the whole-number part of a division, and the modulus %% returns the remainder:

total_bushels <- 1250   # bushels harvested
truck_capacity <- 400   # bushels per truck

total_bushels %/% truck_capacity  # full truckloads: 3
total_bushels %% truck_capacity   # bushels left over: 50

Economics Examples

Let us put these operations to work with a few everyday calculations in agricultural economics.

Unit conversion. Corn is traded in bushels, but international statistics use metric tons. One bushel of corn weighs 56 pounds, and one pound equals 0.45359237 kg:

bushels <- 10000
kg_per_bushel <- 56 * 0.45359237           # 25.4 kg per bushel of corn
metric_tons <- bushels * kg_per_bushel / 1000
round(metric_tons, 2)                      # metric tons


Revenue, cost, and profit for a 500-acre corn farm:

acres <- 500
yield_bu_acre <- 180     # bushels per acre
price <- 4.25            # dollars per bushel
cost_per_acre <- 690     # dollars per acre

revenue <- acres * yield_bu_acre * price
total_cost <- acres * cost_per_acre
profit <- revenue - total_cost
margin <- profit / revenue * 100

revenue; total_cost; profit
round(margin, 1)   # profit margin (%)


Break-even price: the price at which revenue just covers cost.

break_even_price <- cost_per_acre / yield_bu_acre
round(break_even_price, 2)   # dollars per bushel


Percent change in the price of soybeans from one year to the next:

price_2023 <- 13.20
price_2024 <- 10.90
pct_change <- (price_2024 - price_2023) / price_2023 * 100
round(pct_change, 1)   # percent


Compound interest: the future value of $10,000 saved for 5 years at 4% interest per year, using $FV = PV(1 + r)^t$:

PV <- 10000   # present value
r <- 0.04     # annual interest rate
t <- 5        # years
FV <- PV * (1 + r)^t
round(FV, 2)

Converting Between Types

Data often arrive as text. For example, a price scraped from a website may look like "$4.25". To do math with it, remove the dollar sign and convert it to a number:

price_text <- "$4.25"
price <- as.numeric(gsub("$", "", price_text, fixed = TRUE))  # remove "$", then convert
price * 2

quantity_text <- "1,250"
quantity <- as.numeric(gsub(",", "", quantity_text, fixed = TRUE))  # remove the comma
quantity + 1

Formatting Numbers

formatC() adds comma separators and fixes the number of decimals, and sprintf() places numbers inside text:

revenue <- 382500
rate <- 0.0475

paste0("Revenue: $", formatC(revenue, format = "f", digits = 2, big.mark = ","))
sprintf("Interest rate: %.2f%%", rate * 100)
sprintf("Revenue in millions: %.2f M", revenue / 1e6)

Working with Dates

Dates are useful for questions like "how many days until harvest?" or "when does this loan mature?":

planting <- as.Date("2024-04-25")
harvest <- as.Date("2024-10-05")
as.numeric(harvest - planting)   # days from planting to harvest

loan_start <- as.Date("2024-03-01")
maturity <- seq(loan_start, by = "18 months", length.out = 2)[2]  # an 18-month operating loan
maturity

months <- seq(as.Date("2024-01-01"), by = "month", length.out = 6)  # first day of each month
format(months, "%b %Y")

3 Fundamentals

This section covers the building blocks you will use in almost every program: storing data in different structures, making decisions, repeating tasks, and writing your own functions. All examples use simple economics problems.

3.1 Data Structures: Vectors, Named Vectors, Lists, and Sets

R has several ways to store collections of values:

Structure Example Typical use
Vector c(4.25, 4.10, 4.40) a series of values of the same type, such as prices
Named vector c(corn = 4.25, wheat = 5.60) look up a value by its name
List list(name = "Farm A", acres = 500) values of different types and sizes together
Set operations union(), intersect(), setdiff() compare groups of unique items

Vectors keep values in order. Use c() to add new values:

corn_prices <- c(4.25, 4.10, 4.40, 4.55)  # weekly prices, $/bu
corn_prices <- c(corn_prices, 4.60)       # add a new week
corn_prices
length(corn_prices)
round(mean(corn_prices), 3)


Named vectors store name = value pairs, so you can look up a value by its name:

prices <- c(corn = 4.25, soybeans = 10.90, wheat = 5.60)  # $/bu
prices["soybeans"]     # look up a value by its name

prices["sorghum"] <- 4.05   # add a new commodity
prices["corn"] <- 4.30      # update an existing one
prices
names(prices)


Lists can hold objects of different types and sizes, such as the description of a farm:

farm <- list(name = "Prairie View",
             acres = 500,
             crops = c("corn", "soybeans"),
             location = c(lat = 39.19, lon = -96.58))
farm$name
farm$crops
farm$location["lat"]
str(farm)   # compact overview of the list


Set operations compare groups of unique values. For example, the destination markets of two exporters:

exporter_a <- c("Mexico", "Japan", "China", "Colombia")
exporter_b <- c("Japan", "China", "Egypt", "Mexico", "Japan")  # "Japan" twice

unique(exporter_b)                # remove duplicates
intersect(exporter_a, exporter_b) # markets both export to
union(exporter_a, exporter_b)     # all markets
setdiff(exporter_a, exporter_b)   # markets only exporter A serves

3.2 If Statements

if, else if, and else let a program make decisions. The code for each branch goes inside curly braces { }.

Classify a farm's financial result:

profit <- -12500

if (profit > 0) {
  print("The farm made a profit.")
} else if (profit == 0) {
  print("The farm broke even.")
} else {
  print(paste("The farm had a loss of", abs(profit), "dollars."))
}


A price floor: if the market price falls below a support price, a payment covers the difference. (The support price below is hypothetical.)

support_price <- 3.70   # hypothetical support price, $/bu
market_price <- 3.45
bushels <- 50000

if (market_price < support_price) {
  payment <- (support_price - market_price) * bushels
  paste0("Payment: $", formatC(payment, format = "f", digits = 2, big.mark = ","))
} else {
  "No payment: the market price is above the support price."
}


Several conditions can be combined with && (and) or || (or). Here, a loan is approved only if two financial ratios meet hypothetical thresholds:

debt_to_asset <- 0.35
current_ratio <- 1.8   # current assets / current liabilities

if (debt_to_asset < 0.40 && current_ratio > 1.5) {
  "Loan approved"
} else {
  "Loan needs further review"
}

3.3 For Loops

A for loop repeats the same steps for each item in a sequence.

Revenue for each crop on a farm:

crops <- data.frame(crop  = c("corn", "soybeans", "wheat"),
                    acres = c(300, 200, 100),
                    yield = c(180, 55, 50),       # bu/acre
                    price = c(4.25, 10.90, 5.60)) # $/bu

total <- 0
for (i in 1:nrow(crops)) {
  revenue <- crops$acres[i] * crops$yield[i] * crops$price[i]
  total <- total + revenue
  cat(sprintf("%-9s revenue: $%s\n", crops$crop[i], formatC(revenue, format = "f", digits = 2, big.mark = ",")))
}
cat(sprintf("%-9s revenue: $%s\n", "Total", formatC(total, format = "f", digits = 2, big.mark = ",")))


In R, many loops can be replaced by a single vectorized operation, which is shorter and faster:

crops$revenue <- crops$acres * crops$yield * crops$price
crops
sum(crops$revenue)


Growth of an investment year by year:

balance <- 10000
rate <- 0.05
for (year in 1:5) {
  balance <- balance * (1 + rate)
  cat(sprintf("Year %d: $%s\n", year, formatC(balance, format = "f", digits = 2, big.mark = ",")))
}

3.4 While Loops

A while loop repeats as long as a condition is true. It is useful when you do not know in advance how many repetitions you need.

How many years does it take to double an investment at 6% per year?

balance <- 1000
years <- 0
while (balance < 2000) {
  balance <- balance * 1.06
  years <- years + 1
}
years                 # years to double
round(balance, 2)     # final balance


Paying off a $20,000 equipment loan with $5,000 payments per year at 7% interest:

debt <- 20000
payment <- 5000
rate <- 0.07
year <- 0
while (debt > 0) {
  year <- year + 1
  debt <- debt * (1 + rate) - payment   # interest is added, then the payment is made
  cat(sprintf("Year %d: remaining debt $%s\n", year, formatC(max(debt, 0), format = "f", digits = 2, big.mark = ",")))
}

Always make sure the condition eventually becomes false; otherwise the loop runs forever. If that happens, press the stop button in the Console.

3.5 Apply Functions

R's sapply() applies a function to every element of a vector and returns the results, a compact alternative to a for loop. Many operations in R are already vectorized, so you often do not need a loop at all.

Convert nominal prices into real prices (adjusted for inflation) with a price index:

nominal <- c(3.50, 3.70, 4.10, 5.90, 6.50)   # $/bu
cpi <- c(100, 102, 105, 110, 118)            # price index (base year = 100)

real <- round(nominal / cpi * 100, 2)        # vectorized: no loop needed
real


Future value of $10,000 after 10 years at several interest rates:

rates <- c(0.04, 0.06, 0.08)
sapply(rates, function(r) round(10000 * (1 + r)^10, 2))


Keep only the crops whose profit per acre is positive:

profit_per_acre <- c(corn = 75, soybeans = 120, wheat = -20, sorghum = 10)
names(profit_per_acre)[profit_per_acre > 0]

3.6 Functions

A function packages steps you want to reuse. You define it once with function() and then call it as many times as you need.

Net present value (NPV) of a stream of cash flows, $NPV = \sum_t \frac{CF_t}{(1+r)^t}$:

npv <- function(rate, cash_flows) {
  # cash_flows[1] happens today (year 0)
  years <- seq_along(cash_flows) - 1
  sum(cash_flows / (1 + rate)^years)
}

# Buy a $50,000 grain bin that saves $9,000 per year for 8 years
flows <- c(-50000, rep(9000, 8))
round(npv(0.06, flows), 2)   # NPV at 6%
round(npv(0.10, flows), 2)   # NPV at 10%

A positive NPV means the investment earns more than the interest rate used to discount it.
Functions can also have default values for some inputs. Below, the price elasticity of demand uses the midpoint formula by default:

elasticity <- function(q1, q2, p1, p2, method = "midpoint") {
  if (method == "midpoint") {
    pct_q <- (q2 - q1) / ((q1 + q2) / 2)
    pct_p <- (p2 - p1) / ((p1 + p2) / 2)
  } else {
    pct_q <- (q2 - q1) / q1
    pct_p <- (p2 - p1) / p1
  }
  pct_q / pct_p
}

e <- elasticity(q1 = 100, q2 = 70, p1 = 2.00, p2 = 2.50)
round(e, 2)

if (abs(e) > 1) {
  "Demand is elastic: quantity responds more than price."
} else if (abs(e) < 1) {
  "Demand is inelastic: quantity responds less than price."
} else {
  "Demand is unit elastic."
}


Annual payment on a loan, using $A = P\,\frac{r}{1-(1+r)^{-n}}$:

loan_payment <- function(principal, rate, years) {
  principal * rate / (1 - (1 + rate)^(-years))
}
round(loan_payment(150000, 0.065, 7), 2)   # tractor loan, dollars per year

3.7 Anonymous Functions

An anonymous function is a short function without a name, used only once, for example inside sapply(). Since R 4.1 you can also write \(x) as a shortcut for function(x).

Classify farms by size:

farms_df <- data.frame(farm = c("A", "B", "C", "D"), acres = c(120, 850, 2400, 430))
farms_df$size <- sapply(farms_df$acres, function(a) {
  if (a < 500) "small" else if (a < 2000) "medium" else "large"
})
farms_df


Sort crops by revenue per acre:

revenue_per_acre <- c(corn = 180 * 4.25, soybeans = 55 * 10.90, wheat = 50 * 5.60)
sort(revenue_per_acre, decreasing = TRUE)

3.8 Error Handling

Errors happen, for example when data contain a zero or a typo. Note that R returns Inf (infinity) instead of an error when you divide by zero, so it is a good idea to check inputs yourself with stop() and handle problems with tryCatch().

5000 / 0   # R returns Inf, not an error

average_cost <- function(total_cost, quantity) {
  if (quantity == 0) stop("Quantity is zero: average cost is undefined.")
  total_cost / quantity
}

average_cost(5000, 250)

result <- tryCatch(
  average_cost(5000, 0),
  error = function(e) {
    message("Caught an error: ", conditionMessage(e))
    NA   # return a missing value instead of stopping
  }
)
result


Converting messy price data, where some entries are not numbers. as.numeric() turns them into NA and gives a warning, which we can silence once we understand it:

raw_prices <- c("4.25", "4.10", "n/a", "4.40", "")
clean <- suppressWarnings(as.numeric(raw_prices))
clean
round(mean(clean, na.rm = TRUE), 3)   # average of valid prices

3.9 User Inputs

The readline() function asks the user to type a value in the Console. Everything typed comes in as text, so convert it with as.numeric(). Run this chunk yourself in RStudio; it is not run when the notebook is rendered.

Example: change the folder or file name to your own before running
price <- as.numeric(readline("Expected price ($/bu): "))
yld <- as.numeric(readline("Expected yield (bu/acre): "))
cost <- as.numeric(readline("Cost per acre ($): "))

profit <- price * yld - cost

3.10 Objects and Classes

R's simplest object system, called S3, attaches a class to a list. You can then write functions (methods) that work on that class. This is how many R packages, including lm(), are built.

# Constructor: creates a "farm" object
new_farm <- function(name, acres, yield_bu, price, cost_per_acre) {
  structure(list(name = name, acres = acres, yield_bu = yield_bu,
                 price = price, cost_per_acre = cost_per_acre),
            class = "farm")
}

# A generic function and its method for the "farm" class
farm_profit <- function(x) UseMethod("farm_profit")
farm_profit.farm <- function(x) x$acres * (x$yield_bu * x$price - x$cost_per_acre)

# A print method: controls how a farm is displayed
print.farm <- function(x, ...) {
  cat(sprintf("%s: profit %s dollars, break-even price $%.2f per bu\n",

3.12 SQLite Databases

Large datasets often live in databases, which you query with SQL. The DBI and RSQLite packages let R create and query a small SQLite database file. The prices below are simulated for practice. This chunk runs only if RSQLite is installed (install.packages(c("DBI", "RSQLite"))).

library(DBI)

set.seed(7)
months <- format(seq(as.Date("2024-01-01"), by = "month", length.out = 12), "%Y-%m")
price_table <- data.frame(
  month = rep(months, 2),
  commodity = rep(c("corn", "soybeans"), each = 12),
  price = round(c(rnorm(12, mean = 4.4, sd = 0.2), rnorm(12, mean = 11.5, sd = 0.5)), 2)
)

con <- dbConnect(RSQLite::SQLite(), "prices.db")   # creates the file if needed
dbWriteTable(con, "prices", price_table, overwrite = TRUE)

dbGetQuery(con, "
  SELECT commodity,
         ROUND(AVG(price), 2) AS avg_price,
         MIN(price) AS min_price,
         MAX(price) AS max_price
  FROM prices
  GROUP BY commodity")

dbDisconnect(con)

8.1 Regression with Matrix Algebra

Before using lm(), it helps to see what it does. The OLS coefficients solve $\hat\beta = (X'X)^{-1}X'y$, which we can compute with the matrix tools from earlier. We first simulate a small farm dataset:

set.seed(42)
n <- 200
farms <- data.frame(fertilizer = runif(n, 50, 200),          # lbs of nitrogen per acre
                    rainfall = runif(n, 15, 40),              # inches during the season
                    irrigated = sample(0:1, n, replace = TRUE))
farms$yield_bu <- 60 + 0.35 * farms$fertilizer + 1.5 * farms$rainfall +
                  20 * farms$irrigated + rnorm(n, 0, 15)       # corn yield, bu/acre

X <- cbind(Intercept = 1, as.matrix(farms[, c("fertilizer", "rainfall", "irrigated")]))
y <- farms$yield_bu

beta <- solve(t(X) %*% X, t(X) %*% y)   # solves (X'X) b = X'y
round(beta, 3)

# The same estimates with lm()
round(coef(lm(yield_bu ~ fertilizer + rainfall + irrigated, data = farms)), 3)

The estimates are close to the values we used to simulate the data (0.35, 1.5, and 20). They are not exact because of the random noise we added, which is exactly what happens with real data.
