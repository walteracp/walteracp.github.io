1 Introduction to Python

Python is a free, open-source programming language that is widely used for data analysis, statistics, machine learning, and visualization. It is a general-purpose language, so the same skills you learn here will help you clean data, run regressions, build maps, and automate everyday tasks.

Python code is usually written in Jupyter notebooks: documents that mix text, code, and results, just like this one. Each block of code is called a cell, and you run cells one at a time to see their results right below them.

1.1 Installation

You have three easy options:

  1. Google Colab (no installation). Go to https://colab.research.google.com, sign in with a Google account, and create a new notebook. Most packages used here are already installed.
  2. Anaconda. Download it from https://www.anaconda.com/download. It installs Python, Jupyter, and the most common data packages in one step.
  3. VS Code. Install Python from https://www.python.org/downloads and the free editor from https://code.visualstudio.com, then add the Python and Jupyter extensions.

1.2 The Notebook Interface

A notebook has two kinds of cells:

  1. Code cells, where you write and run Python code.
  2. Text (Markdown) cells, where you write notes and explanations.

To run a cell, click inside it and press Shift + Enter, or click the play button next to the cell. The result appears below the cell. Cells share the same memory, so a variable created in one cell can be used in the next ones.

2.2 Python is Case Sensitive

Now run:

x = 5   # re-assign a new value to variable "x"
a = 10
A = 20

5 10 20

You have just seen that you can re-assign a new value to a variable. Be mindful of this as your scripts grow and include many variables.

Also, Python is case sensitive: a above equals 10 and A equals 20.

Putting # in front of a line prevents it from being executed. These comments are useful to leave yourself notes and reminders.

2.3 Missing Values

Python has two common ways to represent a missing value: None (plain Python) and np.nan ("not a number", from the NumPy package). In data analysis you will mostly see np.nan. Keep in mind that a missing value is not equal to zero.

import numpy as np  # NumPy is the core package for numbers and arrays

x = np.nan
x

nan

Math operations with a missing value return a missing value:

print(x + 1)
print(np.sum([1, x, 3]))

nan
nan

However, NumPy has versions of its functions that ignore missing values, similar to na.rm = TRUE in R:

print(np.nansum([1, x, 3]))  # sum, ignoring the missing value

4.0

3.11 System of Equations

Now let us solve the following system of equations:

$$x_1 + 2x_2 = 10$$ $$3x_1 + 4x_2 = 25$$

# In matrix form this is A * X = B
A = np.array([[1, 2],
              [3, 4]])
B = np.array([10, 25])
X = np.linalg.solve(A, B)
X

array([5. , 2.5])

So $x_1 = 5$ and $x_2 = 2.5$.

7.1 Regression with Matrix Algebra

Before using a regression package, it helps to see what it does. The OLS coefficients solve $\hat\beta = (X'X)^{-1}X'y$, which we can compute with the matrix tools from earlier:

X = np.column_stack([np.ones(n), farms[["fertilizer", "rainfall", "irrigated"]]])  # add an intercept column
y = farms["yield_bu"].to_numpy()

beta = np.linalg.solve(X.T @ X, X.T @ y)  # solves (X'X) b = X'y
pd.Series(beta, index=["Intercept", "fertilizer", "rainfall", "irrigated"]).round(3)

Intercept     59.386
fertilizer     0.336
rainfall       1.598
irrigated     16.820
dtype: float64

The estimates are close to the values we used to simulate the data (0.35, 1.5, and 20). They are not exact because of the random noise we added, which is exactly what happens with real data.
